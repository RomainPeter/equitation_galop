# Équi — Mon premier Galop

Application indépendante, non officielle.

## Publication en préparation
Ce premier commit contient uniquement l’enveloppe PWA. Ajouter le fichier complet `Equi.html` à la racine avant activation de GitHub Pages. Sans lui, l’application et le cache hors ligne ne fonctionnent pas.

## GitHub Pages
Après ajout de l’application : Settings → Pages → Deploy from a branch → main → / (root). Adresse attendue : https://romainpeter.github.io/equitation_galop/

## Tablette
Ouvrir le site dans Edge Android et utiliser la commande d’installation ou d’ajout à l’écran d’accueil disponible dans cette version du navigateur. Tester ensuite en mode avion. Les voix distantes ne deviennent pas disponibles hors ligne.

## Mises à jour
Changer le nom du cache dans sw.js après modification des fichiers. Fermer les anciennes fenêtres pour permettre l’activation de la nouvelle version.

## Progression
Les données restent dans le navigateur. Utiliser l’export/import de l’application pour les sauvegarder. Aucun compte ni microphone.
